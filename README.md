# TT 创作助手 · 源码开发版

**最新主流程：AI创作为主。** 进入小说、剧本或文案栏目后选择赛道，给少量方向即可让AI生成方案、大纲和正文；不要求用户先写完整原稿。14份核心赛道规则已实际入请求，人物可从确认的AI方案自动登记。详见 [AI创作主流程整改](docs/AI创作主流程整改.md)。模型设置已简化，低频技术参数默认收起。

**本轮已收敛为开发试用版交付。** 按用户最新要求，UI精修后置；本轮停止扩展功能。启动方式、当前可用范围、已验证结果及后续项见 [交付说明](docs/开发试用版交付说明.md)。此交付不表示整本V1.1交接书已全部完成。

用户授权后的真实软件通道验证：DeepSeek `deepseek-flash` 已实际流式生成一次；Codex CLI 已生成并登记一张原生1024×1536 PNG。已修复真实配置保存及图片工具调度问题。详见 [真实测试报告](docs/M6_真实软件通道测试.md)。其他通道与图片编辑能力没有据此自动验收。

当前阶段：本地工作台、文字通道、事实规则和封面通道已实现核心流程。DeepSeek与Codex图片通道已完成上述真实测试；干净环境首次启动没有预填连接或模拟回复。本机已保存用户明确提供的DeepSeek连接和本次Codex图片连接。

现已增加结构化创作与案例库本地流程，完整交接仍在逐项补缺，不是全部完成。

## 启动

本机直接双击 `启动TT创作助手开发版.bat`。启动器从自身目录定位源码；`local.runtime.json` 已指向经过验证的既有 Python 环境。

更换环境时，将 `local.runtime.example.json` 复制为 `local.runtime.json`，填写已有 Python 3.12+ 的完整路径。安装依赖需要自行执行：

```powershell
& '你的Python路径' -m pip install -r requirements.txt
```

也可以指定环境运行：

```powershell
.\tools\run_dev.ps1 -PythonPath '你的Python路径'
```

启动失败保留窗口说明和 `logs/startup.log`。没有 EXE 或安装包，不依赖 TT 激活。

## 本阶段可用

1. 首页新建小说、剧本或文案项目，双击或“继续创作”打开；项目支持搜索、卡片/列表、重命名、复制、归档与回收恢复。
2. 正文支持手写、撤销/重做、约 1 秒自动保存、Ctrl+S、当前文档查找替换、文字锁、段落批注、确认定稿。拖动目录可排序。输入法组字期间不自动保存。
3. “更多 → 版本与恢复”比较旧版并恢复为新版本；旧版本保留。多个窗口编辑同一文档会进行版本冲突检查，保存失败保留内存草稿并提供另存。
4. Ctrl+O 导入 MD/TXT/JSON/SRT/VTT，确认预览后入库；可选只读来源。未知 JSON 原结构保留，不假装转换为剧本。DOCX 尚未支持。
5. 来源文档“更多 → 从来源建新稿”建立独立新稿，可查看两栏对照，不覆盖来源。
6. 顶部“封面”打开本地排版，可导入底图、修改标题/副标题/作者、比例、字体、颜色及裁切焦点；保存排版、采用封面、恢复旧版本、导出 PNG/JPEG。已提供图片通道与任务界面，真实生图尚未验收。
7. “更多 → 导出全文/选区”输出 MD/TXT/JSON。未定稿会提示。TT 专用导出尚未实现。
8. 首页“项目操作 → 备份项目 / 恢复备份为新项目”包含一致性数据库快照及已登记素材，校验后恢复到新目录。
9. 三主题即时切换，正文和界面字号分别设置；专注模式按 Esc 返回。窄屏助手通过弹层打开。
10. 资料与规则查看 19 份交接基线正文；影视案例库浏览与搜索 6 部作品、7 条改编关系，未知评分/票房不填零。当前只是附件种子，不是全量库。
11. 人物与设定保存事实候选、确认/争议/失效状态、剧情区间和版本来源。“第8章受伤”不会进入第2章有效事实；“提取设定候选”须由用户确认才采用。
12. 规则页支持项目内编辑、JSON/MD/TXT导入并预览、恢复内置版本和选择项目规则。另有3份完整示例与24类基础建议，未补的完整细分明确标记。

## 数据位置

- 项目：源码目录 `user_data/projects/<独立ID>/`，每项目 `project.sqlite`、`assets`、`exports`、`backups`。
- 外观/上次项目偏好：`%LOCALAPPDATA%/TTChuangzuo/preferences.json`。
- 连接配置与加密凭据：`%LOCALAPPDATA%/TTChuangzuo/connections.json`、`credentials.dat`；KEY 不进入项目、备份或日志。助手输入会作本项目创作备忘，用户点击发送时才向所选模型提交冻结范围。
- 开发验收数据位于临时目录并自动清理；首次生产运行不预填演示作品。

## 文字助手使用

进入“模型与设置 → 文字模型”，新增连接，填写名称、服务商、地址/地域与本机 KEY。Codex CLI 填写已有 CLI 路径和实际模型 ID，无需复制认证文件。可先点击“读取模型 / 认证”选择实际 ID；这一步不生成内容。保存后助手底部选择该连接。

“讨论”给建议；“写作”对选区生成替换候选，没有选区时生成光标处插入的文字；“审稿”输出带原文证据的问题。Enter 换行，Ctrl+Enter 发送；发送会使用当前文档/选区、必要文字锁与相关规则，可能收费。可在“上下文”查看冻结快照，“历史 / 用量”看候选、结束状态和未知/实际用量。

写作结果先在助手显示，原稿不变。点击“查看修改”预览并选择接受或拒绝；接受前版本、哈希和锁发生冲突时阻止写入。采纳后 Ctrl+Z 可撤销，再保存为新版本。停止只中断本地等待，不保证服务端停止计费；结果待确认时不自动重发。

最小生成测试会单独显示通道、次数、输出限制和费用未知，用户确认后才执行；不发送作品。固定响应仅存在于隔离开发测试，界面有明确标记。

## 封面图片通道

“模型与设置 → 图片模型”新增独立图片连接，填写实际模型、地址/本机KEY、尺寸和已知能力。CLI填写宿主模型和已有CLI路径。KEY不从文字连接继承；入口检测不生成图片。

“封面 → 生成底图”可直接手写提示词；需要文字策划时填确认简报再单独点击生成提示词。选定图片通道、数量与实际尺寸，查看请求，确认后生成；默认一张无字底图，标题在本地修改。候选要先“用作底图”预览，再明确“设为项目封面”。

网络提交不明时不自动重发。有job_id可查状态；下载失败可只重试下载。停止只中断本地等待，远端仍可能计费。多图部分成功保留成功项。模型内的字是像素，不能用文本框无损改字；可关闭本地叠字或发新的明确生成。

完整边界与证据见 `docs/M4_封面通道验收.md`。本轮仍不制作发行包。

## 创作阶段与案例库

编辑器“创作阶段”选择构思、大纲、小说、剧本、文案、拆解、新方案或改编映射，填写当前章/场/单篇目标并选确认方案。结果先审核，可作为新文档采用。“更多 → 创作设定”设置题材、人群、用途、字数/时长和保留事件；不填不强加。“已确认规划 / 大纲”可将节点落实成目录，节点ID和已有正文保留。

结构化剧本里的对白绑定人物ID；“锁定人物对白”后允许改动作，不能改原句/人物/顺序。确认剧本后导出包含确定性台词本；JSON另保留结构数据。动作行使用 `[动作]` 前缀，对白用已绑定人物名，特殊未识别格式会阻止保存并保留内存稿。

案例库支持六条种子和用户导入的身份、关系、指标历史、收藏、回收与方法候选。指标按平台/币种/日期保留，未知不算0。方法审核后才进入项目，引用版本冻结。详见 `docs/M5_结构化创作与案例验收.md`。

完整控件与验收清单在 `docs/完整交接验收追踪.md`。本轮交付后，UI精修及其他功能缺口作为后续项保留；真实接口在明确允许的通道、资料和预算内再验收，不能据固定响应测试宣称全部跑通。
