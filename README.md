# TT创作助手 · 2.1.0-dev.2

Windows 源码开发版，包含首页、创建剧本、创建小说、仿写内容和设置。当前提交包含本轮 UI、改稿交互与存储改进；没有构建安装包，也不代表所有模型渠道已完成真实账号验收。

## 唯一开发分支与版本

- **只使用 `main`**，作为本仓库唯一长期开发分支。不为每次升级另外创建分支。
- 当前版本：`2.1.0-dev.2`。唯一版本源为 [app/__init__.py](app/__init__.py)，高级设置、启动日志和诊断导出同步显示版本。
- 后续更新继续提交至 `main`，增加开发版本号，例如 `2.1.0-dev.3`，并更新 [CHANGELOG.md](CHANGELOG.md)。版本标签用于定位历史源码，不是新分支。
- 本仓库的工作约定见 [AGENTS.md](AGENTS.md)。

## 启动

需要 Windows、Python 3.12+、PySide6。优先复用已有运行环境，启动器不会自动下载或安装依赖。

```powershell
python -m pip install -r requirements.txt
```

复制 `local.runtime.example.json` 为本机的 `local.runtime.json`，填写现有 Python 可执行程序路径。源码入口为 **启动TT创作助手.bat** 或 **启动TT创作助手.pyw**。

运行环境、连接密钥和作品数据不随 Git 同步。启动失败或操作异常的具体日志路径会显示在弹窗中。

## 使用

1. 在设置中配置文字模型或 Codex 本地通道，保存设置并选择当前使用的模型。图片生成通道独立配置。
2. 首页直接点击“新建剧本”“新建小说”“新建仿写”，进入对应创作设置。已有作品双击卡片继续编辑。
3. 完整首次生成的正文直接保存；已有正文重写或修改先保留为候选。AI 助手显示完整改稿，通过“应用到正文、查看差异、放弃”处理候选。
4. 三个创作页面共享正文编辑工具、历史版本和复制完整正文。标题直接编辑后保存，编辑页不再显示作品管理的“…”菜单。
5. AI 助手有独立字号调节，14–24，点击当前字号恢复16；作品正文的字号独立调节。设置提供三个主题、动态效果和任务提示音。
   左下角可收起或展开侧栏；拖动中间分隔条可将助手加宽至工作区50%，双击分隔条均分。提示音可在高级设置选择，内置三种 WAV，也可在软件 `resources/audio/notifications` 文件夹加入或替换音频后刷新列表。
6. 生成封面在弹窗内操作，支持3:4、16:9、9:16、4:3等比例；默认提示以作品名和故事大纲组织。导出菜单位于导出按钮下方。

## 存储与软件资源

作品、项目数据库、配置、日志、导出和备份由一个可选择的作品总目录管理。默认位于源码文件夹旁的 `TT写作数据`；如果该默认路径处于 C 盘，应先在本机 `local.runtime.json` 的 `data_root` 中填写非 C 盘目录。更换总目录时迁移原数据。

软件图标保存在本仓库 `resources/icons/`，属于软件资源。异常弹窗中的 `logs/startup.log` 是日志路径，不是图标位置。

## 检查与边界

本轮完成相关定向 UI 与交互检查：三页面改稿应用、主题差异配色、首次小说生成、设置完成反馈、菜单锚点、首页卡片、窗口边缘拉伸、标题保存和助手字号。真实接口、音频设备输出和用户电脑上的鼠标手感不由模拟检查证明。

可在已有环境内运行对应的本地检查：

```powershell
python tools/ui_candidate_theme_acceptance.py
python tools/ui_settings_feedback_acceptance.py
```

真实生成测试可能产生费用，仅在明确要求时运行。历史验收记录分别对应当时的源码，不应作为当前提交的全面验收证明。详细更新及验证边界见 [CHANGELOG.md](CHANGELOG.md)。
