## 启动

需要 Windows、Python 3.12+、PySide6。可复用已有环境；启动器不会自动安装依赖。

```powershell
python -m pip install -r requirements.txt
```

复制 `local.runtime.example.json` 为 `local.runtime.json`，把 `python` 改为已有 Python 程序的完整路径；或使用本项目 `.venv`。源码入口为 **启动TT创作助手.bat**。启动失败会保留控制台及 `logs/startup.log`。

## 使用

1. 设置 → 国内大模型：填写接口地址、密钥和实际模型，保存并设为默认。支持 DeepSeek、火山方舟、通义千问、兼容中转；模型可手填。
2. 设置 → 通用生图或 Codex CLI：配置独立图片连接。Codex 使用本机已有登录；文字与生图分别测试，不复制其他软件的密钥。
3. 首页 → 新建项目 → 剧本、小说或仿写。24 个主赛道、144 个细分和结构、情绪、台词规则有实际正文，只有选中规则进入请求。
4. 想法可以留空。长篇先生成规划与第一章，再按章续写；较长单篇自动分段，停止保留草稿。仿写须添加参考，可输出剧本或小说。
5. 右侧说“只改第二场，保留台词”会修改作品；说“检查不要修改”只回复。正文更多菜单可查找、撤销、阅读；右键编辑菜单为中文。
6. 封面自动取当前作品，生成候选后点击采用；导出只包含作品正文。首页双击封面、标题或卡片继续创作。

默认运行数据在 `user_data/projects/<项目目录>/`：数据库、素材、导出、备份。旧项目保留原文和历史，不删除旧库。模型配置与 Windows 加密凭据在 `%LOCALAPPDATA%/TTChuangzuo/`，不进入项目备份、导出或 Git。
