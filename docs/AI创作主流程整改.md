# AI创作主流程整改

2026-10-01。按用户纠正：软件以AI按规则创作为主，手写、改写和审稿作为辅助。Codex接入范围明确为文字／语言模型与生图，不增加语音合成模块。

主入口已经改为：小说／剧本／文案栏目→可选择赛道→少量创作方向（可留空）→AI创作方案→确认→AI大纲→确认→AI正文。用户不用先写故事全文、台词或人物表；已确认AI方案中的人物自动登记，用于后续结构化剧本的说话人绑定。

已新增14份实际核心赛道规则，正文在 `resources/creator_tracks.json`：小说5类、剧本5类、文案4类。选择赛道会设置项目规则ID，TaskService实际冻结并发送该规则全文与哈希；没有将全部赛道混发，也没有只向模型发送赛道名称。原有基础目录仍保留作为补充，不再代替这14份核心规则。

创作主页面、模型设置、规则、案例和结果窗口共享字体、标题、按钮及面板样式。模型设置前台为文字、图片、Codex、外观；技术参数、预算、备份和诊断默认折叠到高级入口。打开已有图片连接会自动载入实际配置；Codex模式隐藏无关API地址和KEY字段。创作结果按可读方案、大纲或剧本显示，而不是在主流程展示JSON。

此前本机3个软件通道实测项目已归档，保留全部文件和结果，可从已归档项目查看；未删除项目。实测连接改为简洁名称，长项目名称预览采用省略显示，避免把整个窗口撑出横向滚动条。

验证：155项既有自动化检查通过；新增17项AI主流程Qt检查通过，覆盖无手写原稿→AI方案→人物登记→大纲→剧本→采用，以及赛道规则入请求和模型表单简化。该17项使用隔离固定响应，明确标记未请求真实创作模型，不把它当成真实AI创作质量验收。此前DeepSeek真实流式连接与Codex真实生图结果保留有效；本轮界面验证没有再消费生成额度。

最新截图：`docs/evidence/ui_AI创作赛道与规则.png`、`docs/evidence/ui_简化模型设置.png`。仍需继续检查参考／改编等其余入口的完整AI操作路径，不能声称全部商业产品体验已完成。旧运行窗口不会自动热更新；保存并关闭后重新启动可加载本次修改。
