## UI 与图像验证

`tools/ui_acceptance.py` 使用实际 QApplication、窗口控件和事件循环，创建隔离的临时项目。默认原生 Windows Qt。13 个检查项通过：空项目启动、真实编辑自动保存、保存失败草稿保留、三主题渲染、1024 紧凑布局、组合输入暂停保存、提交组合文字、专注恢复、真实图片解码导入与封面导出、封面 UI 采用、偏好/项目重开恢复。

保存失败检查使用定向注入 OSError，明确属于故障模拟；其他本地文件往返为真实操作。输入法检查是 Qt 的 QInputMethodEvent，不等同人手使用搜狗/微软拼音完整操作验收。

初次原生基线缩放 devicePixelRatio 为 1.25；本机当前实际倍率以 `ui_results_scale1.json` 为准。早期另以 `--scale 2` 检查放大后的布局；它是本机倍率模拟，不是换到真实 4K 显示器测试。最新首页视觉修改后的额外倍率截图尚未重做，不能据此宣布所有高 DPI 场景已验收。

证据：

- `docs/evidence/ui_results_scale1.json`：基线原生检查结果。
- `docs/evidence/ui_results_scale2.json`：额外缩放检查结果。
- `docs/evidence/ui_石墨深色_scale1.png`、`ui_雾白浅色_scale1.png`、`ui_暖纸写作_scale1.png`：三主题真实截图。
- `docs/evidence/ui_1024_scale1.png`：窄屏助手收起、目录和编辑操作保留。
- `docs/evidence/ui_cover_scale1.png`：封面参数与预览界面。
- `docs/evidence/cover_local_scale1.png`：本地排版真实 PNG 产物，可解码；它是本地模板，不是 AI 生图。

离屏 Qt 首次截图中文为方框，原生 Windows 字体正常。离屏工具后来增加仅测试用系统字体注册；交付视觉依据是最终原生截图，不用离屏成功替代 Windows 视觉检查。
