# M2 文字闭环开发与分项验收

更新：2026-10-01。实际完成四个文字通道的适配源码、设置与异步候选流程；真实账户生成尚未验收，不能把 M2 列为全部通过。

## 已实现

文字连接支持 DeepSeek、火山方舟、千问、Codex CLI 和自定义 Chat Completions。HTTP 地址不强制补 `/v1`，保留方舟 `/api/v3` 和千问 `/compatible-mode/v1`。实际模型 ID 由用户手填或模型列表选择，不把展示名当请求参数。千问地址/地域可编辑。

连接独立保存于应用偏好目录，KEY 由 Windows DPAPI 加密到独立凭据文件，不读取旧 TT KEY。连接文件、作品数据库、任务快照和备份没有明文 KEY。KEY 留空表示保留已有凭据；删除连接同时移除凭据。凭据版本变化会阻止尚未发送的旧任务使用新 KEY。

HTTP 实现流式/非流式、finish_reason、原始及归一化用量。截断和不完整输出不能采纳；网络结果未知不自动重发，明确的认证拒绝不重试。阻止凭据跟随 HTTP 重定向。接收上限 16MB，连接/TLS 阶段最多 15 秒，正文由任务总超时与取消信号控制。Windows 阻塞读取使用可中断 transport，已做真实本机传输定向验证。

CLI 只从指定文件或 PATH 定位，不扫描硬盘；严格手动路径失效不降级。标准 npm 包装器解析为 Node＋codex.js 参数数组，用户提示由 stdin 传递，不拼接到 shell。每次使用独立临时目录、read-only sandbox、忽略用户配置和 execpolicy，关闭 shell、应用、插件、网页、图像等无关工具。JSONL 处理文本、完成、失败及用量，取消终止本地进程树。CLI 输出长度是软限制；套餐用量不换算人民币。

助手支持讨论、写作和审稿。写作候选经过结构检查，原稿只在差异预览后采纳；采纳检查基线版本、原文哈希、选区范围、文字锁，并记录目标 block_id 和检查结果。正文写入和采纳状态在同一事务中完成；Ctrl+Z 可撤销采纳为新版本。审稿只接收来自冻结原文的证据。

任务冻结实际规则全文、文档版本、模型/连接、预算、输入范围及上下文。过期回调不写入切换后的其他项目。任务与用量持久化；进程已结束的中断任务标记“结果待确认”，保留片段，不自动重发。仍存活的任务所属进程不会被误标中断。

预算档最多调用次数为 2/4/8；当前每个助手任务实际只有一次模型调用，没有默认多智能体循环。未知价格、实际费用、未返回的 token 字段保留为未知，缓存读取/推理子项不重复相加。全文项目工具与多轮工具协议属于后续 M3。

## 本机实际检测

新适配器 `CodexTextProvider.detect` 对本机指定 CLI 执行了版本、帮助、feature list 和 login status。结果为 `codex-cli 0.159.2`、已登录、存在工具禁用能力。**没有执行 codex exec 生成，没有图像产物，也没有读取认证文件内容。**

源码实际入口在当前修改后成功启动并定时关闭，输出 `SOURCE_STARTUP_PASS`。整个应用仍是源码开发版。

## 验证结果

累计 46 个 unittest 场景通过，包含旧的 17 项本地数据检查、HTTP/任务/凭据检查及 CLI 子进程检查。

| 范围 | 实测依据 | 边界 |
|---|---|---|
| HTTP 请求与 SSE/JSON 解析 | 固定响应 opener，验证三通道原生路径、参数、结束原因、取消及 usage | 不代表服务商账户可用 |
| Windows HTTP 取消 | 实际 localhost HTTP server 延迟关闭流；取消后保留片段并在 2 秒内返回 | 不代表远程服务停止计费 |
| HTTPS 参数兼容 | Python 3.12 原生 HTTPS handler 构造，证书/主机验证保留 | 没有远端 TLS/认证生成验收 |
| Windows DPAPI | 用测试字符串实际加密/解密，检查项目/连接/快照无明文 | 测试 KEY 不是用户账户 KEY |
| CLI 进程和 JSONL | 实际 Python 子进程输出固定 CLI 事件；中文路径、取消进程树、stdin 与 argv | 固定事件不代表 Codex 模型生成 |
| 本机 Codex 检测 | 新适配器执行本机 CLI 检测 | 检测和登录不代表文字/图片生成通过 |
| 采纳与冲突 | 选区外文字不变、版本冲突拒绝、文字锁回滚、错误 JSON 不采纳 | 尚无真实成稿质量评分 |
| 中断恢复 | 验证所属进程失效/仍存活两种场景，不新建替代请求 | 历史任务的服务端结果查询尚未接入 |

`tools/text_ui_acceptance.py` 使用实际 Qt 事件循环与清楚标记的固定响应，验证：后台生成时原稿不变、异步候选、固定响应不标真实账户已测试、确认采纳、撤销保存、设置不回显 KEY、切换项目回调隔离、窄屏助手与恢复分栏。证据 `docs/evidence/text_ui_results.json`，截图 `ui_助手固定响应测试.png` / `ui_文字模型设置.png`。

已发现并修正的问题：Windows socket 在有 Python timeout 的模式下，shutdown 后仍等待一次 select/读取；改为由 deadline timer 控制的阻塞 receive，通过本机实际 HTTP 传输检查。另核对 Python 3.12 HTTPSHandler 仅使用 context，避免调用不存在的 `_check_hostname` 属性。
