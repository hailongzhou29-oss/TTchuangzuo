# M3 上下文、事实与规则开发验收

日期：2026-10-01。M3 核心数据与受控工具已实现并完成离线验证；真实模型工具能力、完整创作 Stage、价格及金额预留机制尚未验收/完成，不把整个项目标为完成。

## 已实现的工作流

“更多 → 人物与设定”管理人物、地点、商品等对象和事实。事实先为候选，用户明确确认后成为指定剧情区间的已确认设定；争议、失效项独立保存。手工修订重新成为候选，原来源与内容保留在不可变历史版本。当前文档剧情位置可手动调整，拖动目录不改既有剧情位置。

事实提取使用原文版本、段落 ID 和逐字证据；输出全部验证后一次事务写入候选区，不直接确认。来源版本已变时阻止确认旧候选。第8章开始的伤情不进入第2章事实上下文。

规则页包含交接原文 19 份核心规则、3 个完整细分示例和24类基础目录。基础建议明确标示“完整细分待补”，不默认全库加载。规则支持项目内编辑、JSON 包预览导入、MD/TXT 导入后设置元数据、恢复内置为新版本、选择项目适用规则。项目覆盖保存在数据库，原始资源不改；每次新任务读取最新有效规则，旧任务保留实际全文及哈希。

助手支持新会话、当前项目固定资料、查看冻结上下文、再生成、本地引用到正文、续接未完成候选。再生成使用新请求且不复用旧创作候选；不把旧偏移量套到别的文档或新版原文。本地引用产生待审核提案，不请求模型。续接片段明确作为资料，不能把片段里的“忽略规则”等字句变成权限授权。

已确认正文可生成有原文证据的章节摘要候选，并由用户采用。可选择复用未变化的分析；事实、规则或文档变动使相关缓存失效，强制“再生成”不复用。清理分析缓存不删除正文、事实、素材、封面或历史任务。

## 受控项目工具

HTTP 连接须由用户声明支持项目函数工具；默认关闭。当前在讨论模式按需使用：`search_project`、`read_document`、`read_facts`、`read_rules`、`propose_patch`、`propose_fact`、`validate_draft`。CLI 使用本地预组装上下文，不宣称其原生函数工具已验证。

工具参数完整并通过白名单和 schema 检查才执行；输入只认当前项目对象 ID，没有任意路径/SQL/外部导出/网络搜索权限。文档读取绑定本次版本清单，默认不读取未来章节；用户固定的参考材料单独可见。模型修改只能形成提案，事实只能进入待确认区。

工具续轮保留完整 assistant/tool 协议及必要的原始协议字段。每次模型调用独立记录 usage，按任务汇总但不重复加缓存/推理子项。达到 2/4/8 次数上限、上下文上限或重复同参数工具调用时停止，不自动无限循环。工具执行失败明确记录，不包装成已完成正文修改。

多条修改先预览，再在一笔事务中采纳；任意基线、范围、哈希或文字锁冲突均整批回滚。正文/事实/规则/固定资料已变时，旧候选不得直接覆盖。

## 数据与凭据边界

数据库升级到 v3 前分别保留旧版一致性备份。复制项目保留创作资料，不携带模型会话、账本和派生缓存；恢复备份的未完成任务标为待确认，保留原快照和片段，不在新目录自动重发。

更换服务商或域名会清除该连接的有效凭据引用，需重新输入。凭据按版本绑定到加密存储，配置文件保存失败时旧配置仍绑定旧凭据；兼容原有密钥条目，不跨域继承。删除连接移除各版本凭据。

本次资料如果包含当前连接真实凭据，提交前拒绝；响应若回显凭据，即使拆成多个流式片段，也不会进入 UI、原始用量或任务落盘。流式接收保留一段安全缓冲尾部，停止/完成后统一脱敏输出。

## 实际验证

截至本阶段，共77项 unittest（17本地基础、4CLI进程、29文字/凭据、27项目上下文）通过。新增定向验证覆盖：

- 未来状态隔离、候选/争议不成为事实、来源变更拒绝旧确认。
- 原文与规则快照不受后续编辑影响、规则包脚本字段拒绝、同版不同内容拒绝。
- 外项目对象/路径/导出/执行工具拒绝、完整工具参数才执行、协议闭合、每轮账本。
- 重复循环停止、批量锁冲突回滚、分析缓存仅显式复用、再生成不复用。
- 复制不带模型会话、备份快照不伪装活任务、凭据改域不继承、配置写失败保持旧绑定。
- 本地引用不调用模型、未完成片段只作为资料、跨流式片段凭据回显脱敏。

`tools/knowledge_ui_acceptance.py` 6项实际 Qt/本地操作通过：点击真实确认弹窗采用事实、第2/第8剧情位置筛选、46条规则目录显示、项目覆盖刷新、新会话保留已确认事实。证据：`docs/evidence/knowledge_ui_results.json`、`ui_人物事实与剧情区间.png`、`ui_规则库与基础目录.png`。

原助手9项 Qt集成、本地基础13项界面检查通过。数据/接口检查中的模型响应为明确标记的固定测试数据；本机 HTTP 取消使用真实 localhost 传输，CLI 检查使用实际子进程；均不等于真实服务商生成。当前源码入口实际启动成功。
