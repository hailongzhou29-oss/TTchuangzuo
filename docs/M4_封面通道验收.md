# M4 封面通道开发与验收

日期：2026-10-01。已实现通用图片/CLI适配、持久化任务与封面候选流程；真实服务商和CLI生图尚未生成验收，没有把固定PNG响应当作模型产物。

## 已实现

图片连接独立于文字连接，配置文件 `image_connections.json`，凭据使用新应用的版本化安全存储。填写实际图片模型或CLI宿主模型、原生尺寸、数量及编辑/蒙版/seed/独立负面提示能力声明。未知能力默认关闭；文字KEY和文字测试不会赋予图片权限。

HTTP适配支持 `/images/generations` JSON、`/images/edits` multipart、Base64/临时URL结果，以及明确配置的服务端任务查询路径。编辑失败不自动改为文生图、不猜上传或轮询接口。请求先保存完整快照，同一任务禁止重复提交；提交超时没有任务号时标结果待确认，不自动重生。

图片下载不转发API Authorization，限制协议、来源域名、内网地址、重定向及30MB大小；Base64限制解码量。签名链接与尚待下载的传输数据在项目内DPAPI加密，不出现在公共结果。原始Base64和签名URL不会因日志脱敏被改坏。产物必须是完整可解码的PNG/JPEG/WebP，保存实际尺寸、MIME与SHA256，原子落盘后登记。

多图部分成功保留成功项；“重试下载”只补缺失，不发生成。按job_id查询使用GET；不是再次生成。CLI接入复用文字桥的发现、参数数组/stdin、超时和进程树取消，单独启用内置图片工具，关闭shell/应用/网页等无关工具。按本次返回会话ID读取唯一任务目录，拒绝只返回文字、旧PNG、路径越界及数量异常，不搜索全盘或自动切API。

封面窗口分“本地排版 / 生成底图”，生成、停止和用作底图固定在预览区底部。支持参考/蒙版、尺寸/数量、请求预览、独立模型设置、查询/重试下载、候选回收恢复、设为封面及历史版本。无字底图为默认；模型生成文字明确为栅格内容，本地标题层可关闭。PNG透明背景与JPEG合成背景分开处理。

文字封面策划只发送确认的标题、简报、比例及参考用途ID，不默认整部作品。返回概念、正负提示、参考绑定、文字模式、精确标题区域、剧透级别和待确认项，本地验证后仍由用户采用；采用方案不会自动生图。已有提示词可跳过文字模型。简介/事实更新只标旧任务“项目依据已更新”，不自动扣费重做。
