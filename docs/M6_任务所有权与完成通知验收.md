# M6 任务所有权与完成通知验收

日期：2026-10-01。范围为本地执行、图片查询／下载接手、恢复与界面通知；全项目未完成。

本轮增加独立的执行所有权记录，保存任务ID、执行操作、进程号和进程创建时间；不修改冻结的生成参数。SQLite事务保证两个窗口不能同时提交、查询或下载同一任务。同一同步流程中的提交→下载、查询→下载共用一次执行记录，结束或异常时解除活动状态。

恢复和回收检查优先读取当前执行所有权，不再仅依赖首次提交进程。进程创建时间用于识别进程号重用；无法读取身份时采用保守判断。图片候选正在处理时不能回收。项目数据库升级到v6，升级前保留一致性v5备份；恢复备份时清除执行所有权，不把原进程的执行状态转移到新项目。

`test_task_runtime.py` 的5项检查通过，包括两个实际Python进程之间的接手：首个进程用固定响应提交任务后退出，第二个进程接手查询并停在可观测等待点；此时恢复不会误标中断，另一个查询／下载不会调用提供方，回收被拒绝。继续后得到可解码PNG，登记素材，查询与下载分别执行一次，冻结快照逐字不变。提供方始终是隔离固定响应，不是实际模型接口。Windows Python启动器和实际执行进程号可能不同，测试使用执行进程报告的身份。

Qt检查发现并修复了“结果已落盘而界面仍显示运行中”：文字和图片Worker保留完成事件与结果，界面按完成标记补收结果，并防止通知重复处理。主动屏蔽完成信号后，候选按钮仍正常恢复。封面文字策划和图片界面共用该完成机制。

当前完整自动化套件148项通过，日志为 `docs/evidence/unit_results_current.log`；其中5项为新增运行时检查。文字助手10项、图片助手7项及项目页Qt检查通过，源码启动检查通过。测试数量与交接书148控件没有一一对应关系，不能据此宣称控件、54场景或视觉全项完成。
