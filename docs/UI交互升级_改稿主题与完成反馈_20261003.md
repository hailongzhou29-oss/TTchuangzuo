# UI 交互升级交付

本轮修改源码，覆盖剧本、小说、仿写的共用交互及用户追加的首页和设置问题。没有构建、安装依赖、调用真实模型或读取生产作品。

## 已修改

- 顶部状态固定预留文字宽度，显示真实任务阶段、经过时间、轻量转圈及轮换文案。例如构思、生成正文、生成改稿、整理、保存、等待应用。没有编造进度百分比，状态不再挤占正文上方的一行。
- 切换主题时重新计算差异高亮，删除和新增各有主题配色，并明确设置高亮文字颜色。保留对比模式、文本选区和滚动位置，避免深色主题出现白底浅字。
- AI 助手显示完整候选正文，随后给出修改说明。应用之后仍保留完整结果，刷新对话与切换主题也能恢复。完整首次生成的正文同样显示在助手内。
- 删除顶部和消息里的重复“查看改稿”，右侧统一为“应用到正文、查看差异、放弃”。对比界面的候选选择与右侧操作同步；窄窗口隐藏助手时保留对比界面的应用入口。未结构化回复仍要求核对范围和勾选确认。
- 首次生成且基线为空、正文完整时直接保存正文。附属摘要失败单独提示，不再把初稿当作改稿。已有正文重新生成仍保留原稿，需明确应用；取消、基线冲突和未结构化修改的校验继续生效。
- 导出菜单与导出按钮右边缘对齐，在按钮下方约 4 像素展开，不再锚定正文框右上角。
- 首页卡片宽度从 200–260 调整为 300–320 逻辑像素，按视口重新计算列数。“生成封面”按钮保留完整宽度，标题和操作位于封面下方。
- 设置页处理反馈移到标题旁。模型列表成功读取后显示实际数量，停止忙碌动画。未自行更新状态的回调也会清除“正在处理”，错误保留错误提示。
- 高级设置加入“任务完成时播放”开关与“试听”。使用 Windows 系统提示音异步播放，不新增媒体依赖。模型读取、设置检测、写作任务及封面生成完成会提示；失败、取消不播放完成音。开关保存在应用配置中。
