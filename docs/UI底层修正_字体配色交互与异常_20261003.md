# UI 底层修正交付

本轮修正三个创作页面共用的界面与改稿交互。不构建、不打包，不批量读取作品、原始响应或账号凭据。仅读取截图对应异常日志尾部和相关实现；验证使用隔离微型项目及本地模拟模型。

## 已确认并修复的异常

- `NoneType.count`：改稿面板还把正文工具栏当作旧的 QLayout，升级为 QWidget 后 `.layout()` 为空。改为引用共享 `editor_toolbar`、`editor_footer`，不再通过布局序号猜控件。
- `float(None)`：悬停动画未初始化插值端点，设置起止值时可能发送空值。端点初始化为浮点数，并忽略空值；没有把异常简单吞到全局入口。
- 阅读模式先关闭当前改稿面板，再显示正文。退出后恢复正文工具栏与有效状态，不留下半打开的候选页面。
- 底部拉伸改为可命中的透明边缘控件，鼠标按下、移动、释放直接更新窗口几何尺寸，四角合并两个方向。摆脱只返回 Windows 命中代码却不能真正拉伸的问题。

## 字体与尺度

简体中文 UI 优先 Microsoft YaHei UI，兼容其中文字体名及现有候选字体。默认正文与界面分角色；字号用 Qt 逻辑像素，屏幕缩放负责物理大小。

| 角色 | 默认字号 | 字重 |
|---|---:|---|
| 页面一级标题 | 28 | 600 |
| 分区标题／AI 面板标题 | 20 | 600 |
| 控件文字／AI 正文 | 16 | 400 |
| 字段标签／辅助信息 | 14 | 400 |
| 保存与任务状态 | 15 | 500／常规 |
| 作品正文／改稿预览 | 18，可按原规则调整 | 400 |

简体中文字体选择参考 [微软 Windows Typography](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/typography)。上述具体层级是本产品落地值，不声称每项都照搬 Windows 默认值。

表单字段统一总高度 44，标签高度 22，消除原来样式最低 40 而控件最大 38 的冲突。父容器按实际尺寸布局，不通过缩小字体遮掩裁切。

## 配色与动态

- 保留三个主题，调整背景、面板、主文字、次级文字和描边角色。主文字使用中性色，强调色用于操作和选中，保存状态独立表达。
- 主题色数值检查：清透白主文字／面板 14.61:1，次级文字／面板 6.32:1；石墨紫对应 13.77:1、7.65:1；暖纸色对应 14.54:1、6.45:1。这些数值只证明所检查角色的颜色对比，不代表全面无障碍认证。
- 修正 QTextBrowser 视口右键菜单的主题继承。只读回复保留复制、全选，避免系统黑色菜单与应用主题不一致。
- 将任务状态移到页面标题旁；成功反馈短暂显示，待应用和错误保留，不再占正文上方一整行。
- AI 消息消除空的链接段与多余空白段，统一角色标识、段落和操作链接颜色。
- 动态遵循快速反馈、稳定命中、可中断原则，参考 [Windows Motion](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/motion)。不以整段文字缩放或持续晃动替代反馈。
- 输入框、数字框和标签上的滚轮转交可滚动的上层区域；输入选项不因滚轮而改变。内部编辑区滚到边界后可继续滚动外层设置页。
- 滚动位置保存由 250 毫秒延后至 900 毫秒，减少短暂停顿时的界面线程写入。本轮未宣称测得具体帧率或耗时改善百分比。

## 改稿闭环

- “帮我拓展到60秒”等直接修改指令进入 modify 路径；明确只讨论的指令仍不改正文。
- 三页面共享右侧固定操作区：应用到正文、查看差异、放弃。
- 结构化完整候选经既有版本、范围、锁定与冲突校验后应用；未结构化回复先打开核对面板，必须确认正文及范围，不能直接绕过人工核对。
- 应用后同步正文、版本、字数与保存状态；原版本保留。放弃只改变候选状态，原稿保持。
- 精简作品菜单中的重复版本历史、改稿、动效入口；正文与台词冲突仅在实际标记存在时提供处理入口。

## 定向验证及边界

运行 `tools/ui_foundation_fix_acceptance.py`，Windows 原生 Qt 平台共通过八组检查：三个页面分别验证改稿／阅读／应用／保存，以及字段完整／滚轮／空值动画；三主题 AI 右键菜单；底部拖动改变窗口高度。三页面均额外验证放弃候选不修改正文。

未处理异常列表为空，当前测试字体为 Microsoft YaHei UI，付费调用数为零。测试使用本地模拟响应，不表示真实模型请求已重新跑通；物理鼠标在用户当前窗口中的拖动还需重启后使用验证。没有运行全仓回归或构建。
