## 可直接使用

双击根目录 **启动TT创作助手.bat**；原“启动TT创作助手开发版.bat”同样进入 V2。已通过实际批处理的运行环境检查和 `app.main` 启动检查，复用本机 Python 3.12.9、PySide6 6.11.1。启动检查改为文件入口，避开 Windows PowerShell 对内嵌 Python 引号的处理差异；失败保留控制台及日志。

## 本轮改变

- 五个一级页面：首页、剧本、小说、仿写、设置。全部页面、子面板、输入框、编辑菜单采用中文与统一的三主题样式；产品名、模型标识、接口地址保留必要原名。
- 一键生成直接写入统一正文，没有“先确认想法，再确认大纲”的卡点。剧本第三部分由程序提取对白，包含旁白，并排除含冒号的场次标题与动作说明。
- `CurrentWork` 将编辑器、助手、生成、封面绑定到同一作品。修改绑定项目、文档、版本和选区；只检查不改正文，局部修改及规划修改可撤销。
- 24 主赛道、144 细分、30 结构公式及情绪、台词、语言、商业规则编译为 268 条有正文的规则。请求展开选中规则及父规则，不发送全部目录。规则版本和项目覆写保留。
- 小说规划、章节续写、当前版本上下文和失效标记；较长单篇支持自动分段，连续生成按用户指定范围请求。仿写支持文本参考及剧本/小说输出。
- 设置为主页面；国内文本模型、通用图片和 Codex 配置分开。支持手填模型、独立密钥、图片路径和允许下载域名。修正旧 DS 实测配置的 128 输出限制，只调整已知测试配置，保留密钥引用并备份原配置。
- 自动封面读取当前故事，生成候选、本地中文排字、明确采用。修复采用后首页未绑定封面及旧卡片短暂重叠的问题，复用已生成图片复核，没有追加生图请求。
- 自动保存、修订恢复、回收站、项目备份、保留源副本的数据迁移；保留旧项目原文和数据库历史。未验证的 TT 原生导出入口隐藏。

主要新增文件：`app/core/work_context.py`、`selection.py`、`creation_flow.py`；`app/ui/v2_window.py`、`creation_page.py`、`assistant_panel.py`、`settings_page.py`、`project_home.py`、`materials_panel.py`、`cover_panel.py`、`v2_widgets.py`、`chinese.py`；`resources/v2_rules.json`。沿用项目存储及文本/图片 Provider，不迁入原 TT 的授权或激活流程。

## 已知限制与后续验收

- 本轮可用开发版不等于六题材商业内容质量全部验收。历史、家庭、带货、探店和用户真实仿写参考仍需评审。
- 火山、千问、第三方中转、通用生图没有本轮真实账号测试；Codex 纯文本创作也未单独真实验收。
- 长内容分段已用固定响应验证，没有付费跑完整长剧/长篇。单段超出模型能力会保留草稿并报错，不无限重试；全书复杂修改仍建议按章进行。
- 仅编辑第三部分台词本时会标记对应位置待确认，请在第二部分修改对白。复杂手工格式、实际中文输入法、硬崩溃与磁盘满仍需专项验收。
- 影视资料支持本地结构、导入和筛选，现有少量种子不代表收齐 1980–2026 全球资料；不编造奖项、评分、票房和来源。
- 官方默认地址复核来源：[DeepSeek](https://api-docs.deepseek.com/quick_start/pricing-details-cny/)、[火山方舟](https://docs.volcengine.com/docs/ark/chat-api?lang=en)、[通义千问](https://help.aliyun.com/zh/model-studio/base-url)。接口地址可手填；模型名称和价格没有作为固定可用清单写死。

本次后段收尾范围曾持续扩大，已停止新增功能。以上明确区分已验证、未测与待完善项，供这一版源码评审。
