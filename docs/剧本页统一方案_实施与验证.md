## 已实现

- 共享导航与外壳、右侧助手非零宽度恢复，反复收起、切页、阅读模式返回及重启恢复；模型配置仍只有助手底部一份，生成底栏只引用名称。
- 设置／正文两页签；基本六项、观看视角／影像载体／叙事手法、六个详情页签。当前内容决定卡片高度，每页展开状态独立保存；中央滚动不挤掉生成按钮和右侧输入。
- 原生控件使用统一颜色、字体、间距与焦点样式。自由创作不打开空细分菜单；搜索空态明确，弹层依屏幕边界定位；已选标签可移除。窄窗口自动变为两列或一列。
- 24主赛道、144细分、30公式、24情绪、41叙事规则以及审定的形式、语言、载体等目录。599个目录选择位置、511个唯一ID均有规则正文与版本，重复引用项共享ID。自动为空约束，未选目录不发送；599个位置逐个进入真实请求准备流程验证。
- 规则文件缺失、损坏／无法读取、目录或分组为空显示不同错误；不伪装为自动，不导致整个应用启动失败。目录不可用时暂停相关控件与生成，原选择、正文和想法保留；可安全重试，成功后恢复原选择。失败期间不进行旧值迁移，恢复后再迁移。
- 语言预设、声音来源与传播方式分开；无语言排除隐藏密度、语速、词量、段数与比例。语言密度和有效语速分别预算；明确不兼容的锁定、词量、时长或结构选择阻止提交，其他组合给建议。
- 父级切换保留原父项草稿，返回恢复；无效子项不进入请求。旧值迁移保留原配置和含混历史要求，并提供查看入口；含混值不自动注入。AI采用值单独保存在结果设置中，不回写用户选择。
- 参考编辑、文件导入、已有作品读取、多个来源与主参考、名称参考状态；引用资料和有效规则分开处理。既有项目人物补全与稳定ID绑定。
- 生成、讨论、检查、修改真实任务链；最新编辑器文本进入冻结快照。保存项目／文档／基线版本／请求ID／规则版本与有效设置。
- 三段共享有序发声记录，区分对白／旁白／内心与传播方式；第三段从正文提取，无语言明确写“本作品无发声台词”。修改和保存更新记录版本，导出检查缺失、重复、次序及原文一致性。
- 同一文档手动编辑、编辑后撤回、保存到新版本等使请求基线失效时，结果只保存为候选。作品菜单提供比较与明确应用为新版本；取消输出保存在未完成候选，原正文保留。
- 正文与第三部分同时手改、先改第三再改正文、没有旧发声记录的既有不一致草稿，均先保存完整用户文本为版本并保留草稿，不静默擦掉第三部分。未解决时持续标记不同步，完整导出阻止不一致；重开恢复文本与提示。作品菜单“处理正文／台词不同步”提供“保留正文并重建台词”和“先保留草稿”，返回／取消不改变文本。明确重建后原手改版本与草稿仍保留；不提供双向语义合并器。空正文显示“暂无正文”，封面／导出禁用。

## 预算实现与估算边界

- 自动密度按现有形式／语言模式选策略：口播、访谈、旁白、自述、对镜和问答采用语言密集区间；剧情短片、原创电影感片段优先留白；其他形式交替安排动作与发声采用均衡。采用区间、策略、语速及估算边界记录到结果采用值，用户字段不回填。
- 中文按有效语速和发声汉字量规划；明确记录边界作为发言段数，**不声称已经语义合并连续发言**。数字和外语特殊读法提示不确定。
- 无时间戳的结果记录 `time_windows_available=false`，文字摘要明确是估计，**不具备精确重叠时间窗并集测量**。没有伪造start／end或实测数据。
- 已知非中文目标或结果没有适用估算器时，可靠词量／发声秒数留空，显示不支持可靠估时，不套中文参数。尚无其他语言专用估算器；少量混合外语和数字仍须实际读法校准。
- 旁白与对白比例按同一有效语速估计各自发声时间，排除内心声音，不按段数计算。与指定比例偏差超过5个百分点提示估计风险，或无法估计时说明；不凭软估计硬拦截，不自动改句。
- 自动语速／密度仅软建议；明确指定语速、硬词量、锁定原句和时长无法兼得时给出冲突。无语言与锁定发声内容仍是硬冲突。没有配音或成片测量，不承诺实际秒数。

## 启动与用户截图步骤

双击已有 `启动TT创作助手.bat`；或在当前源码目录运行：

```powershell
$taskPython = (Get-Content -LiteralPath local.runtime.json -Raw | ConvertFrom-Json).python
& $taskPython -m app.main
```

如需完全隔离用户已有项目和渠道，可指定新的可写目录：

```powershell
& $taskPython -m app.main --data-root '.\review_data' --preferences '.\review_data\settings\preferences.json'
```

1. 新建剧本，保持默认，截图完整“创作设置”；确认正文区域没有在设置下方占位。
2. 选择悬疑及多项细分，切战争再切回；截图恢复的标签。逐个查看六页签，分别展开更多，再切回，确认无最长页签留白。
3. 选择主观男友、手机随拍、信息揭示；再比较“面向观众＋观众男友＋交流女友”。检查语言模式与来源、台词页密度的位置；无语言应隐藏预算项。
4. 点击顶栏助手收起／展开多次，切首页返回，关闭重启；截图展开、收起及恢复。缩窄窗口，确认下方生成与助手模型／输入／发送可见。
5. 正文可导入已有无费用文字用于查看；不要为截图调用付费模型。截设置与正文切换、空正文状态。模拟结果、取消、迟到回包与候选应用已由上述隔离工具验证。
6. 修改第二／第三部分为不同原句，保存并重开；作品菜单进入“处理正文／台词不同步”。截图保留草稿与明确重建入口，先保留或返回都不丢文本；重建后的旧手改全文仍可在版本历史查看。

如需复现本地模拟截图，运行 `& $taskPython tools/script_unified_acceptance.py`。该工具不会使用用户项目或付费连接，结束后关闭自己的窗口并清理临时数据。
