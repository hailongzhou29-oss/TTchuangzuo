# TT创作助手商业 UI 升级交付

日期：2026-10-03。交付类型：源码升级；未构建 EXE、未打包、未安装依赖。

## 完成范围

本轮按已经确认的截图总结与静态审计执行，覆盖首页、剧本、小说、仿写、设置、AI 助手和封面面板。没有批量读取现有作品、历史模型响应或账号凭据，没有迁移或删除实际用户数据。

- 增加 48 逻辑像素的统一标题栏；支持最小化、最大化／还原、双击标题栏、系统拖动及 Windows 窗口边缘缩放。窗口操作图标按应用主题着色，避免系统深色主题导致浅色界面图标不可见。
- 调整导航宽度、字号、文字角色、卡片圆角、输入框边框与间距。确认当前中文字体解析为 Microsoft YaHei，并具备“创”等中文字符的原生字形支持。
- 共用 `EditorToolbar`、`EditorFooter` 和 `TaskStatus`，三个创作栏目同步使用相同编辑入口与反馈。
- 撤销、重做、查找、版本历史、阅读模式常显。版本历史新增“对比当前正文”，预览、对比与恢复分别操作；普通编辑撤销与 AI 改稿撤销的文案区分。
- 正文底栏增加字数与“复制完整正文”；多章节小说提供“复制整本”，不附加大纲、对话和候选。字号调整只更新正文相关组件，避免重新应用整窗主题。
- 窄窗口将工具栏变为两行，保持字号按钮紧凑和复制、生成操作可见。阅读模式退出时恢复进入前的 AI 面板状态。
- 首页“写剧本、写小说、开始仿写”及新建菜单修正布尔参数覆盖问题。情绪排序、移除已选项、对话历史的相同回调模式一并修正。
- 下拉弹层使用无系统边框、透明圆角、细描边；更多菜单统一薄边圆角；模型搜索补全窗口移除系统粗框与重阴影。
- 按钮增加可中断的悬停颜色过渡；展开使用局部高度动画，重新计算滚动锚点采用内容坐标，避免视口滚动与补偿互相影响。
- 增加真实运行的轻量加载指示；状态说明保留固定区域，不再贴边单独出现。高级设置提供全局标准／减少动态选择。
- AI 消息区增加角色标识、标题、正文、强调、列表和操作区域层级。用户向上阅读时新消息保留当前位置，并显示“查看新消息”。修改结果撤销明确标为“撤销本次 AI 改稿”。
- 模型启用后显示绿色“当前使用中”并停止重复启用；存在未保存修改时显示“请先保存修改”，与正在查看的渠道区分。
- 首页封面直接打开原位弹窗，三个栏目复用。打开、关闭与采用不切换正在编辑的另一作品，采用后只更新目标项目封面。
- 封面常用比例为 3:4、16:9、9:16、4:3，并保留 1:1、2:3；显示请求画幅与产物实际像素信息。
- 默认封面提示词仅由名称、明确故事大纲及用户选定设计参数组成。删除自动附带正文前 1800 字与项目记忆的逻辑；大纲缺失提示补充。重新填入手工修改的提示词有确认步骤。
- 封面弹窗提供预览空态、可编辑大纲、提示词和固定底部生成／采用操作，生成按钮不会被右侧设置滚动区藏起来。

## 定向验证

使用既有 Python 3.12 / PySide6 运行 `tools/commercial_ui_acceptance.py`，在单独的微型测试工作区发送 Qt 鼠标事件。没有启动付费生成服务，未读取生产项目。

Windows 原生 Qt 平台最终验收覆盖 13 组场景：

1. 首页三个创建入口、启动首页和新标题栏。
2. 新建项目菜单真实选择及圆角浮层。
3. 剧本的撤销、重做、查找、版本历史与对比、复制、字号、阅读模式。
4. 小说的对应编辑操作及整本复制内容。
5. 仿写的对应编辑操作及小说输出的整本复制内容。
6. 补充设置连续点击、展开与滚动稳定。
7. 下拉选择、无系统粗框、透明边角像素。
8. 首页封面原位打开、四画幅进入请求、名称与大纲取材、关闭恢复。
9. 采用测试封面只更新对应项目，首页与在用作品保持。
10. 加载指示运行及 AI 消息层级。
11. 三主题与三个正文栏目共同渲染。
12. 窄窗口三个栏目中的复制与生成按钮仍在窗口内。
13. 模型启用及未保存修改状态反馈。

另外完成 100%、125%、150%、200% 四档 Qt 缩放模拟，每档通过 11 组核心场景；Windows 原生平台测试的实际 DPR 为 1.25。检查并修正窗口图标与紧凑工具栏排版后做了原生复验。

相关 12 个 UI 源文件完成定向语法检查。截图已经查看；没有扩大为全仓回归。
