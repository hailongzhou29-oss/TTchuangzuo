# TT创作助手精准源码升级

执行范围：源码及图标升级；未构建、未打包软件，未批量读取或迁移现有作品、历史记录或原始模型响应。

## 已完成

- 首页项目卡片底部直接显示“重命名、生成封面、导出、删除”。“删除”沿用项目移入回收站的操作，按钮文案已缩短。
- 项目单击选中后改变背景和边框，双击进入作品；栏目、标签、选项区分选中状态。
- 软件启动先进入首页，不自动恢复上次项目。
- 五栏目共用字体层级及主按钮、选中、辅助、成功、警告、错误配色。
- 高级设置恢复“雾白浅色、石墨深色、暖纸写作”三个原始主题及基础颜色，立即切换并保存。
- 三个正文编辑器都有“− / 当前字号 / ＋”，范围 12–32；点击字号恢复 18。字号跨页面和重启保存，不改变正文和导出内容。
- 使用本机中文字体、抗锯齿和字体提示改善渲染；高 DPI 下的实际屏幕效果仍需在用户显示器查看。
- 默认软件数据根目录为 `J:\精简版本\TT写作数据`。正文、图片、项目数据库、设置、日志、缓存和 Codex 验证记录均在此目录下。
- 软件自身默认数据路径不再依赖 C 盘 AppData；选择 C 盘数据根目录会被拒绝。Codex 自己的账号凭据和宿主工具目录仍由 Codex 管理。
- 选择新的空文件夹后，迁移整个当前软件数据目录，更新输出路径、在用项目和启动定位。迁移成功后清理旧目录；失败时继续使用原目录。
- 移除高级设置中的旧设置记录及历史目录入口，不自动扫描历史项目。
- Codex 登录检测和真实成功调用会保存验证记录，无软件自行设置的过期时间。重启、切页及启用已验证模型不重复检测；保留用户手动重新检测。网络或检测异常不清除已有成功登录记录，明确授权失败会更新状态。
- 原生 SVG 图标及 16、24、32、48、64、128、256 尺寸 ICO 已生成，接入窗口、应用标识和源码快捷方式。桌面快捷方式已写入 `E:\桌面\TT创作助手.lnk`。

## 定向验证

使用现有 Python / PySide6 环境，通过 `tools/precision_upgrade_acceptance.py` 运行 10 组隔离检查：启动首页、卡片按钮与选择、主题及五栏目渲染、字号无正文副作用、图标、登录缓存、目录迁移、无凭据解密迁移、失败回退和重启持久化。

验收过程发现并修复 Windows 下 SQLite 连接未关闭导致的目录占用。修复后定向检查通过，验收截图已查看。

证据：`docs/evidence/precision_upgrade/results.json` 与同目录的首页、正文、高级设置截图。截图中的作品及登录状态均来自人工构造的小型测试数据，不代表真实账号验证。

## 使用与边界

- 完全退出已有软件窗口后，从桌面“TT创作助手”快捷方式重新启动源码版，即可使用新界面。
- 本轮没有迁移或删除旧的 C 盘实际数据，也没有查询真实 Codex 登录或提交生成请求。开发版按新的单目录结构启动，不加载旧的 C 盘配置和历史项目。
- 目录迁移仅对当前软件使用的数据总目录执行；目标要求独立、为空、不在 C 盘、不与原目录互相包含。
- 旧目录被其他进程占用时，软件会报告清理未完成；已启用的新目录仍可继续使用。
- 窗口及任务栏图标已接入代码，快捷方式图标写入已核验；Windows 实际任务栏显示与用户屏幕上的高 DPI 清晰度未现场实测。
- 未生成 EXE 或安装包，未做全量回归。
- 自动审批策略拒绝清理第一次失败验收的临时目录 `logs/precision-ui-0m6bib7a`，返回“策略阻止”；该目录保留，不涉及实际作品数据，不影响后续通过的验收。
